# Screenshots for pull requests

Images linked from pull requests opened from this fork to [NotRexed/Hookshot](https://github.com/NotRexed/Hookshot).
Not code, and never merged anywhere.

The HDR10 captures (NVIDIA app, JPEG XR) are tone-mapped to SDR for the web: the paper white to white, the highlights up
to the display's peak (800 nits) rolled off, then shrunk to 1920 or 2560 pixels wide. Taken on an RTX 5080 at 3840x2160.
